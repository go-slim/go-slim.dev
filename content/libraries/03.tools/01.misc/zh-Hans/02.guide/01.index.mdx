# 指南

按当前需要的具体操作选择 helper。即使 helper 缩短了代码，信任、所有权和错误策略仍应留在应用中。

1. [HTTP 与 client IP](/zh-Hans/libraries/misc/guide/http-and-client-ip)：请求检查和受信代理边界。
2. [Digest 与函数组合](/zh-Hans/libraries/misc/guide/digests-and-composition)：checksum、密码 hash 和顺序函数。
3. [模板与值](/zh-Hans/libraries/misc/guide/templates-and-values)：插值、泛型值和 ordered math。

使用涉及 aliasing、unsafe 或 deprecated 语义的 API 前，阅读[进阶](/zh-Hans/libraries/misc/advanced)。
