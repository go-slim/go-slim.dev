# Guide

Start from the input contract rather than the function catalog. Compose only the shape checks the application needs, then select focused predicates for individual values.

1. [Validate user input](/libraries/is/guide/validate-user-input) composes required, format, enum, and length rules.
2. [Find a predicate](/libraries/is/guide/find-a-predicate) maps common questions to focused APIs.

Read [Advanced](/libraries/is/advanced) before treating a successful shape check as a security or trust decision.
