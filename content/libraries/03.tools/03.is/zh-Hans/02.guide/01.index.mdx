# 指南

从输入契约出发，而不是先浏览函数目录。只组合应用必需的形状检查，再为单个值选择职责聚焦的谓词。

1. [校验用户输入](/zh-Hans/libraries/is/guide/validate-user-input)：组合必填、格式、枚举和长度规则。
2. [查找合适的谓词](/zh-Hans/libraries/is/guide/find-a-predicate)：把常见问题映射到具体 API。

把形状校验成功当作安全或信任结论前，阅读[进阶](/zh-Hans/libraries/is/advanced)。
