# Guide

The package is still in design. Verify the source before adopting it, then learn the intended parse-once/render-many model without treating untested behavior as a contract.

1. [Integration readiness](/libraries/icu/guide/integration-readiness) lists current blockers and the checks required before adoption.
2. [Message model](/libraries/icu/guide/message-model) explains parsing, variables, selection, plural branches, and rendering expectations.

Continue to [Advanced](/libraries/icu/advanced) for formatter and extension boundaries.
