# Advanced

Formatting and extension APIs define long-lived runtime behavior. Treat formatter registration as startup configuration and distinguish implemented syntax from the wider ICU MessageFormat specification.

- [Formatting, extension, and boundaries](/libraries/icu/advanced/formatting-and-extension) covers locale, plural, context, custom formatters, and concurrency expectations.
