# Guide

The guide covers the day-to-day h3 workflow. Read it in order if you are new to the package:

1. Start an app and shut it down explicitly.
2. Declare routes with standard `http.ServeMux` patterns.
3. Compose middleware across route trees.
4. Understand routing fallbacks, app lifecycle, and servlets.

## Recommended path

| Page | What you should get from it |
| --- | --- |
| [Getting started](/libraries/h3/guide/getting-started) | A complete runnable server with explicit signal-driven shutdown. |
| [Routing](/libraries/h3/guide/routing) | ServeMux patterns, mounts, publication, redirects, and 404/405 boundaries. |
| [Middleware](/libraries/h3/guide/middleware) | Composition order, parent/child wrapping, and shared state rules. |
| [Lifecycle](/libraries/h3/guide/lifecycle) | Start/stop behavior, rollback, restart-safe servlets, callbacks, and shutdown limits. |

After this section, move to [Advanced](/libraries/h3/advanced) when you need component ownership or lower-level response/server control.
