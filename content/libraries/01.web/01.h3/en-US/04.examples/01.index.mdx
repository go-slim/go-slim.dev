# Examples

These examples show how h3 fits with adjacent go-slim packages and standard `net/http` middleware.

| Example | Shows |
| --- | --- |
| [JSON API](/libraries/h3/examples/json-api) | h3 routes, binding, content negotiation, and JSON errors. |
| [Component worker](/libraries/h3/examples/component-worker) | A mounted component with lifecycle-managed background work. |
| [Response logging](/libraries/h3/examples/response-logging) | Access logging with final status and response size. |

Treat examples as starting points. Keep validation, persistence, and business error mapping in application code.
