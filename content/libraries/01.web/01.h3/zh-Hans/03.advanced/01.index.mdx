# 进阶

h3 的进阶用法主要围绕 ownership 边界：

- 谁拥有 route declarations；
- 谁拥有后台资源；
- 谁拥有 HTTP server lifecycle；
- 谁拥有协议层 response 行为。

当应用拆成多个模块，或需要更严格的生产控制时，这些主题会变得重要。

## 主题

| 页面 | 重点 |
| --- | --- |

| [Route compilation](/zh-Hans/libraries/h3/advanced/route-compilation) | 有意识地使用不可变 snapshots 和 `CompileRoutes`。 |
