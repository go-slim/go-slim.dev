# 示例

这些示例展示 h3 如何与相邻 go-slim 包和标准 `net/http` middleware 组合。

| 示例 | 展示内容 |
| --- | --- |
| [JSON API](/zh-Hans/libraries/h3/examples/json-api) | h3 routes、binding、content negotiation 和 JSON errors。 |
| [Component worker](/zh-Hans/libraries/h3/examples/component-worker) | 带生命周期管理后台工作的 mounted component。 |
| [Response logging](/zh-Hans/libraries/h3/examples/response-logging) | 使用最终 status 和 response size 做 access logging。 |

示例只是起点。验证、持久化和业务错误映射仍应留在应用代码中。
