# middleware

`go-slim.dev/middleware` provides focused HTTP middleware that follows the standard library conventions. Every constructor returns:

```go
func(http.Handler) http.Handler
```

It can wrap `http.ServeMux`, h3, or any compatible router without introducing a framework-specific context, handler signature, or application lifecycle.

## Install

```sh
go get go-slim.dev/middleware
```

The module requires Go 1.25.5 or later.

## Minimal example

```go
mux := http.NewServeMux()
mux.HandleFunc("GET /health", func(w http.ResponseWriter, r *http.Request) {
	w.WriteHeader(http.StatusNoContent)
})

handler := middleware.Recover()(
	middleware.RequestID()(
		middleware.RequestLogger()(mux),
	),
)

log.Fatal(http.ListenAndServe(":8080", handler))
```

The outer middleware sees the request first and the completed response last. In this example, requests flow through `Recover → RequestID → RequestLogger → mux`; responses return in reverse order.

<Callout title="Boundary">
  Middleware is appropriate for cross-cutting HTTP policy. Route ownership, domain logic, response schemas, and application startup remain the caller's responsibility.
</Callout>
