# NonWWWRedirect

`NonWWWRedirect` 在 host 以 `www.` 开头时发送 redirect，并保留当前 scheme、path 与 query string。

```go
handler := middleware.NonWWWRedirect()(mux)
```

例如，`https://www.example.com/docs?q=go` 会转到 `https://example.com/docs?q=go`。已经是 non-www host 的请求直接进入下游。

## 配置

```go
redirect := middleware.NonWWWRedirectWithConfig(
	middleware.RedirectConfig{
		Code:    http.StatusPermanentRedirect,
		Skipper: skipInternalHealth,
	},
)
```

默认状态码为 301，有效范围为 300 到 308。这个 middleware 不改变 scheme；需要同时强制 HTTPS 时使用 `HTTPSNonWWWRedirect`。

选择永久状态前确认缓存与客户端行为。非 GET 请求需要保留方法和 body 时，优先使用 307/308。
