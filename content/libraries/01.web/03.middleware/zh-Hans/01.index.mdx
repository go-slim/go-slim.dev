# middleware

`go-slim.dev/middleware` 提供一组遵循标准库约定的 HTTP middleware。每个构造函数都返回：

```go
func(http.Handler) http.Handler
```

因此它可以包装 `http.ServeMux`、h3 或任何兼容 router，不要求框架专属的 context、handler 签名或应用生命周期。

## 安装

```sh
go get go-slim.dev/middleware
```

模块要求 Go 1.25.5 或更高版本。

## 最小示例

```go
mux := http.NewServeMux()
mux.HandleFunc("GET /health", func(w http.ResponseWriter, r *http.Request) {
	w.WriteHeader(http.StatusNoContent)
})

handler := middleware.Recover()(
	middleware.RequestID()(
		middleware.RequestLogger()(mux),
	),
)

log.Fatal(http.ListenAndServe(":8080", handler))
```

外层 middleware 最先收到请求，最后看到响应结果。上例的请求顺序是 `Recover → RequestID → RequestLogger → mux`，响应则沿相反方向返回。
