# Guide

Follow the direction of the HTTP exchange: validate what the client sent, then choose a representation the server can return.

1. [Matching Content-Type](/libraries/nego/guide/matching-content-type) covers aliases, wildcards, parameters, and unsupported-media-type policy.
2. [Negotiating representations](/libraries/nego/guide/negotiating-representations) covers quality, specificity, token fields, charset, encoding, and language.

After matching works, continue to [Advanced](/libraries/nego/advanced) for cache reuse, `Vary`, and application policy.
