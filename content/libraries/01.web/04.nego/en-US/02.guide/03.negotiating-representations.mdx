# Negotiating representations

Create one reusable negotiator and provide server offers in preferred order:

```go
var negotiator = nego.New(128)

mediaType, err := negotiator.Accepts(
	r.Header.Get(nego.HeaderAccept),
	nego.MIMEApplicationJSON,
	nego.MIMEApplicationXML,
)
```

`Accepts` returns the original offered string. No acceptable offer returns `"", nil`; an invalid server offer returns an error.

## Quality and specificity

For each server offer, the most specific matching client range determines effective quality. This is important for explicit exclusions:

```http
Accept: text/*;q=1, text/plain;q=0
```

`text/plain` is rejected even though the broader `text/*` has quality 1. The package then chooses the offer with highest effective quality; server offer order breaks equal-quality ties.

Other rules:

- Missing or whitespace-only `Accept` behaves as `*/*`.
- `q=0` rejects a representation.
- Type, subtype, and matching media parameters increase specificity.
- Malformed client list members are dropped individually; remaining members still participate.
- A server offer may not carry the reserved `q` parameter.

## Return aliases with Type

`Type` reads the request field and expands the same aliases as `TypeIs`, while returning the caller's alias:

```go
kind, err := negotiator.Type(r, "json", "xml", "text")
switch kind {
case "json":
	w.Header().Set(nego.HeaderContentType, nego.MIMEApplicationJSONCharsetUTF8)
case "xml":
	w.Header().Set(nego.HeaderContentType, nego.MIMEApplicationXMLCharsetUTF8)
case "text":
	w.Header().Set(nego.HeaderContentType, nego.MIMETextPlainCharsetUTF8)
}
```

Candidate order is server preference, not a fallback that overrides client exclusions.

## Charset

```go
charset := negotiator.Charset(r, "utf-8", "iso-8859-1")
```

Exact case-insensitive matches override wildcards. A missing `Accept-Charset` selects the first offer; a present but empty field accepts none.

## Content coding

```go
encoding := negotiator.Encoding(r, "br", "gzip", "identity")
```

`Accept-Encoding` has special identity rules:

- missing selects the first offer;
- present but empty accepts only `identity`;
- `identity` defaults to quality 1 unless explicitly assigned or excluded;
- `identity;q=0`, or `*;q=0` without a more specific identity entry, can exclude it.

Do not set `Content-Encoding` for `identity`.

## Language

```go
language := negotiator.Language(r, "zh-Hans", "en-US")
```

Language selection uses RFC 4647 Basic Filtering. `en` matches `en` and `en-US`, while `en-US` does not match the broader offer `en`. More specific client ranges override broader ranges for the same offer; server order breaks equal quality.

A missing `Accept-Language` selects the first offer, while a present but empty field accepts none. The chosen language is still an application decision: it does not automatically rewrite URLs, load translations, or set `Content-Language`.
